# Cat Breed Explorer

A cat encyclopedia and personal cat registry — users browse cat breeds from an API and register their own individual cats locally.

## Language

**Breed**:
A cat breed as defined by The Cat API — a category like "Persian" or "Siamese" with encyclopedia-level data (description, origin, temperament, life span).
_Avoid_: Cat (when referring to the API-sourced breed catalog)

**Registered Cat**:
An individual cat created by the user — a specific animal with a name, age, and photo that belongs to a Breed.
_Avoid_: Custom cat, local cat, created cat, saved cat

**Breed List**:
The screen that displays Breeds fetched from the API.
_Avoid_: Cat list (ambiguous now that Registered Cats have their own list)

**My Cats**:
The screen that displays Registered Cats stored locally on the device.
_Avoid_: Saved cats list, registered cats list
